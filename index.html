Justificación

Por qué una red interactiva

Codificación visual

Los nodos codifican entidades musicales y las aristas codifican colaboraciones. El color separa álbumes, el tamaño destaca la centralidad y el trazo discontinuo diferencia una co-colaboración entre artistas.

Interactividad

El filtrado por álbum, la búsqueda y la selección directa permiten comparar subconjuntos, detectar conexiones concretas y reducir ruido visual durante la exploración.

Limitaciones

La red es una muestra acotada y no representa toda la discografía ni todas las relaciones disponibles en MusicBrainz. Su valor principal es explicar estructura, comparación y método.

Transparencia Declaración de uso de IA

Para esta práctica he utilizado una herramienta de inteligencia artificial generativa como apoyo limitado durante el proceso de prototipado y desarrollo técnico de la visualización web.

Herramienta utilizada: ChatGPT / Codex, de OpenAI.

Objetivo del uso: la herramienta se ha utilizado para ayudar a estructurar el dashboard en HTML, CSS y JavaScript, generar una primera versión interactiva de la red de colaboraciones, proponer ajustes visuales de paleta y tipografía, y preparar un guion breve de apoyo para la presentación oral.

Prompts o instrucciones principales empleadas: crear una visualización web interactiva a partir de los archivos nodes.csv y edges.csv; incluir filtros por álbum, búsqueda, leyenda, panel de detalle y gráficos de apoyo; cambiar la paleta visual para evitar tonos sepia o marrones; usar Helvetica como fuente principal; y preparar un guion breve para explicar la práctica.

Respuesta obtenida: la herramienta propuso y generó una estructura inicial de página web con archivos HTML, CSS y JavaScript, además de textos auxiliares para la metodología, la presentación y la publicación del proyecto.

Proceso de revisión y edición: el contenido generado fue revisado y ajustado manualmente. Se comprobaron los datos de nodos y aristas, se corrigió la relación de Tainy para usar Callaita en lugar de Moscow Mule, se revisó la coherencia de la paleta visual, se ajustó la tipografía y se verificó que la visualización respondiera a los objetivos de la práctica.

Limitaciones: la IA se ha usado como apoyo para prototipar y redactar materiales auxiliares, no como sustituto del análisis ni de la revisión crítica del proyecto. No se ha introducido información personal, confidencial ni protegida.
