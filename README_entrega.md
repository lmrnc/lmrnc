# PEC4 - Red de colaboraciones MusicBrainz

## Archivos principales

- `index.html`: página web de la visualización.
- `styles.css`: diseño visual y composición.
- `app.js`: datos, interacción y renderizado SVG.
- `nodes.csv`: nodos originales de la red.
- `edges.csv`: relaciones originales de la red.
- `notas_metodologia.txt`: notas metodológicas de la primera parte.
- `guion_video.md`: guion orientativo para el video de 6-8 minutos.

## Cómo abrir la visualización

Abre `index.html` directamente en el navegador. La visualización es autocontenida y no necesita instalar librerías externas.

## Cómo publicarla para obtener un enlace web

Opción sencilla con GitHub Pages:

1. Crear un repositorio nuevo en GitHub.
2. Subir todos los archivos de esta carpeta.
3. Entrar en `Settings > Pages`.
4. Seleccionar la rama principal y la carpeta raíz.
5. Usar el enlace generado por GitHub Pages como enlace de entrega.

Opción alternativa:

Subir la carpeta a Netlify o Vercel como sitio estático. El archivo de entrada es `index.html`.
